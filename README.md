## 🎨 About Neo-Portfolio

This project acts as my personal interactive playground (Sandbox) where I implement cutting-edge frontend stacks alongside intelligent API structures:

> ### 🔮 Core Architecture Highlights
> *   **The Engine:** Built on **React 19** and **Vite 6** for ultimate, hot-reloading pipeline efficiency.
> *   **The Styling System:** Uses the compiled architecture of **Tailwind CSS v4** for clean, low-overhead asset footprints.
> *   **The Motion:** Powered by a modern **Motion Engine** to ensure layouts and view changes feel physics-based, physical, and frictionless.
